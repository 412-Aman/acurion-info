02 Security

Case data stays private and every change stays visible.

Encrypted case workspace

AES-256-GCM with a key from a PBKDF2-SHA-256 passphrase. It locks itself after 15 minutes idle.

Tamper-evident audit trail

Every change is SHA-256 hash-chained. Verify integrity names the first altered event.

Signed reports

Each package carries a SHA-256 fingerprint and an ECDSA P-256 signature, so any later edit shows.

Role-based access

Analysts, reviewers, admins and viewers, enforced by the database’s own rules rather than the page.

No direct line to the host

Start, Pause and uploads pass through Firebase rules. The backend key never reaches a browser.

Browser hardening

A strict Content Security Policy and security headers, plus Mask personal data for screen sharing.
